## Why these were removed from the main project
These documents presented DTechLab as having multiple product divisions (Nexus, AutoPro,
a digital store, etc.) when DTechLab Studio is currently a one-person web design studio.
Keeping them at root level created a misleading impression of the business scope.

## Can be deleted?
Yes. They served as brainstorming artifacts. If any ideas from them become real,
they should be rebuilt from scratch with accurate scope.
