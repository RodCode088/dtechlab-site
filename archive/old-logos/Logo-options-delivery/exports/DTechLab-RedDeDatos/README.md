# DTechLab — Logo Kit · "Red de datos"

Marca alternativa basada en **cuatro nodos conectados** (datos / IA), conservando
la lectura de los 4 bloques del logo original. Misma paleta de marca.

## Colores de marca
| Uso | Hex |
|-----|-----|
| Azul primario (marca sobre fondo oscuro) | `#5B6AFF` |
| Azul reversa (marca sobre fondo claro) | `#3A4AFF` |
| Fondo Void (negro de marca) | `#050507` |
| Texto oscuro (Graphite) | `#111118` |
| Blanco | `#FFFFFF` |

Tipografía del wordmark: **Space Grotesk** Semibold (600), tracking -0.02em.
Nodos llenos (#5B6AFF/#3A4AFF) en diagonal; nodos secundarios al 40–45%.

## Estructura
```
DTechLab-RedDeDatos/
├─ svg/                       Master vectorial (escalable)
│   ├─ dtechlab-mark.svg            marca sola, azul primario
│   ├─ dtechlab-mark-light.svg      marca sola, azul reversa
│   ├─ dtechlab-lockup-dark.svg     marca + "DTechLab" blanco
│   └─ dtechlab-lockup-light.svg    marca + "DTechLab" oscuro
├─ png-mark-transparent/      Solo marca, fondo transparente (16→1024 px)
├─ png-mark-on-black/         Marca sobre #050507 (128→1024)
├─ png-mark-on-white/         Marca sobre blanco (128→1024)
├─ lockup/                    Logo horizontal completo, 2000 px
├─ favicon/                   favicon.ico (16/32/48) + apple-touch + maskable
└─ google-workspace/          Listo para subir a Google Workspace
```

> Nota de legibilidad: a **16 y 32 px** la marca se simplifica a solo los 4 nodos
> (sin líneas) para mantener nitidez. De 48 px en adelante se muestra la red completa.

## Qué subir en Google Workspace
1. **Logo de empresa** → `google-workspace/company-logo-320x132-light.png`
2. **Avatar / perfil** → `google-workspace/profile-avatar-512.png`
3. **Favicon** → `favicon/favicon.ico` + `favicon/apple-touch-icon-180.png`
4. **Firma de correo** → `lockup/dtechlab-lockup-on-white.png` o `...-light-transparent.png`

> Para web y firmas, prefiere los SVG de `svg/` cuando el medio lo permita.
